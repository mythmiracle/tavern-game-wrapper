게임 실행 & 세이브 · 모드 관리

① 게임 실행 파일 선택과 ② 기존 세이브 백업 불러오기는 순서에 상관없이 언제든 하실 수 있습니다. 준비가 끝나면 하단의 게임 시작하기를 눌러주세요.

💡 크롬·엣지 등 인터넷 창에서 플레이하던 세이브를 가져오시나요?

백업 도구를 인터넷 창으로 열어 기존 세이브와 모드 설정을 파일로 받아보세요

이전에 플레이하던 세이브는 원래 사용하던 인터넷 창(크롬, 엣지 등) 안에 들어 있으므로, 백업 도구를 인터넷 창에서 열어 파일로 저장하시면 됩니다.

1단계 · 백업 도구 열기

우측 상단의 🌐 인터넷 창으로 백업 도구 열기 버튼을 누르면 평소 쓰시던 인터넷 창(크롬·엣지 등)에서 백업 도구가 열립니다.

2단계 · 세이브 백업 파일 내려받기

열린 화면에서 💾 백업 파일 내려받기를 누릅니다. (만약 목록이 0개로 보이면, 기존 게임 화면에서 F12 키를 누른 뒤 아래쪽 입력칸에 비상용 자동 백업 명령어를 붙여넣고 Enter를 누르세요.)

3단계 · 아래에서 백업 파일 불러오기

내려받은 파일을 아래 우측의 📂 백업 파일 불러오기 버튼으로 선택하면 기존 세이브와 모드 설정이 그대로 적용됩니다.

게임 파일 설정 · 언제든 변경 가능 미지정

게임 실행 파일 위치

다른 폴더나 다른 드라이브에 있는 게임 실행 파일을 선택해도 원본 파일을 수정하지 않고 안전하게 연결합니다.

현재 선택된 게임 파일 -
아직 선택된 게임 파일이 없습니다.

※ 새 버전의 게임이 나왔을 때도 여기서 새 게임 파일만 골라주시면 기존 세이브가 그대로 이어집니다.
