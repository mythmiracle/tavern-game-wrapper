1. 백업 파일 내려받기

아래 💾 백업 파일 다운로드 버튼을 눌러 파일을 저장한 뒤, 런처 화면의 📂 백업 파일 불러오기에서 선택해 주세요.

💡 혹시 현재 화면에서 찾은 항목이 0개로 나오나요?

크롬·엣지 등 인터넷 창에서는 보안 설정상 파일마다 저장 공간이 따로 분리되어 있을 수 있습니다. 이 경우 원래 게임을 플레이하던 인터넷 창 탭에서 F12를 눌러 콘솔(Console) 창을 열고 아래 비상용 자동 백업 명령어를 붙여넣은 뒤 Enter를 누르면 백업 파일이 바로 내려받아집니다. 

(() => { const a = document.createElement('a'); a.href = URL.createObjectURL(new Blob([JSON.stringify(localStorage, null, 2)], {type: 'application/json'})); a.download = 'localstorage-backup.json'; a.click(); })()
